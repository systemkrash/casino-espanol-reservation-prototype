# Casino Español Sports Reservation Prototype

Interactive React and Ant Design UI/UX prototype for the proposed private sports-facility reservation system.

## Live preview

https://systemkrash.github.io/casino-espanol-reservation-prototype/

## Included

- Seven-day reservation calendar
- Tennis, badminton, pickleball, and bowling
- Court and lane selection
- Reservation confirmation and push-reminder option
- Member reservation management
- Staff/admin dashboard
- Responsive desktop and mobile layouts

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This is a front-end prototype using sample data. Laravel API integration, production authentication, database storage, and live Web Push delivery are not included yet.
